# UGNX--Flange-Forging-and-M# 
Flange Forging & Machining – CAD Model

## Project Overview

Designed and modeled a **Flange** using **Siemens NX (UG NX)**, focusing on forging geometry, machining allowances, and accurate dimensional features.

## Features

* Created a detailed 3D flange model
* Developed forging geometry with machining considerations
* Applied accurate dimensions and geometric constraints
* Created bolt holes and bore features
* Focused on manufacturable and functional design

## Software Used

* Siemens NX (UG NX)
* 3D CAD Modeling
* Parametric Modeling

## Skills Demonstrated

* Forging Component Design
* Machining Considerations
* Solid Modeling
* Mechanical Component Design
* Precision CAD Modeling
